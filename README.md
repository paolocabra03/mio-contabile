# Mio Contabile

Web app personale per iPhone, installabile sulla schermata Home, che legge e scrive in un foglio Google.

- `index.html`, `app.js`: l'app
- `config.js`: Client ID di Google (identificativo pubblico, non dà accesso ai dati)
- `sw.js`, `manifest.webmanifest`, `icons/`: installazione e funzionamento offline

Il foglio da usare si sceglie al primo avvio e resta salvato solo sul telefono. Nessun dato è in questo repository.
